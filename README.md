# Job Portal Backend

This is the backend for a Job Portal System built using Node.js, Express, and PostgreSQL.

The project supports basic authentication and will be extended to handle job postings, applications, and resume uploads.

---

## Tech Stack
- Node.js
- Express.js
- PostgreSQL
- JWT Authentication

---

## Features (Current)
- User registration
- User login
- Password hashing with bcrypt
- JWT-based authentication
- Role-based users (recruiter, jobseeker)
- Clean MVC-style project structure
